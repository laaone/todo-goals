# 할 일 관리 앱 PRD

##  Why - 목적
* 단순 할 일 나열을 넘어 1년 장기 목표와 일일 실행 단위를 계층적으로 연결
* 일일/주간 단위 실행 결과를 상위 목표 진행률에 실시간 반영하여 목표 달성률 극대화

##  Who - 타깃 사용자
* 장기 목표(1년 단위)를 세우고 주간/일일 단위로 쪼개어 실행하려는 개인 사용자
* 직관적인 상태 전환(칸반)과 목표 대비 진척도를 한눈에 파악하고자 하는 사용자

##  User Flow
* 최초 사용
   1. 1년 목표 기반으로 이번 주 계획 작성
   2. 주간 계획 기반으로 할 일 생성

* 일상 사용
  1. 대시보드에서 이번 주 계획 확인
  2. 할 일 생성 / 수정
  3. 드래그앤드랍으로 상태 변경 (todo → doing → done)
  4. 완료 작업이 주간 진행률에 자동 반영

## 기능 요구사항

### P0 — 핵심 기능
* 할 일 관리
  * 할 일 생성 / 수정 / 삭제
  * 상태 변경 (todo / doing / done)
  * 드래그앤드랍으로 상태 이동

* 주간 계획
  * 이번 주 목표 생성 (최대 3~5개)
  * 요일별 할 일 배치
  * 주간 메모 작성

*목표 관리
  * 1년 목표
  * 목표별 설명 작성

* 연결 구조
  * 할 일 → 주간 계획 → 1년 목표

###  P1 — 추가 기능
* 우선순위 설정 (High / Medium / Low)
* 마감일 설정
* 주간 진행률 자동 계산 (%)
* 목표별 진행률 표시
* 주간 회고 작성
